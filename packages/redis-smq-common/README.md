# RedisSMQ Common

`redis-smq-common` provides shared utilities and types for the RedisSMQ ecosystem — configuration helpers, logging interfaces, Redis client abstractions, and more.  

This package is part of the [RedisSMQ monorepo](https://github.com/weyoss/redis-smq), which contains the full TypeScript implementation.
